## Programação Orientada a Objetos com Java

Este espaço reúne anotações, exemplos práticos e exercícios desenvolvidos durante a disciplina de **Programação Orientada a Objetos II (POO2)**.

Os conteúdos exploram os principais conceitos da linguagem Java e da orientação a objetos, com foco em código claro, reutilizável e organizado.

### Conteúdo

- Classes, objetos, atributos e métodos
- Encapsulamento, herança e polimorfismo
- Classes abstratas e interfaces
- Sobrecarga e sobrescrita de métodos
- Coleções, exceções e boas práticas
